# แบบงาน: Tag ของ Texture และการค้นหา Drawable

## เป้าหมาย

ให้ผู้ใช้ใส่ Tag แยกสำหรับ Texture แต่ละรายการ เช่น กำหนด `Gang 2` ให้ Texture `jbib_diff_013_a_uni` แล้วค้นหา Drawable ที่มี Texture นั้นผ่านช่องค้นหาด้านซ้ายของโปรแกรม

## แนวทางที่พิจารณา

- ใช้ Tag ของ Drawable เดิมแทน Tag ของ Texture: ทำได้ง่าย แต่แยก Tag ของลายแต่ละรายการใน Drawable เดียวกันไม่ได้
- เพิ่ม Tag ให้ Texture แต่ละรายการ และนำ Tag เหล่านั้นไปรวมในการค้นหา Drawable: แยกความหมายของแต่ละลายได้ และใช้ตัวแก้ไข Tag ที่โปรแกรมมีอยู่แล้ว แนวทางนี้เป็นแบบที่เสนอ

## การทำงาน

- Texture แต่ละแถวมี Tag ของตัวเอง ผู้ใช้เพิ่มหรือลบ Tag ของ Texture ที่เลือกได้ด้วยตัวแก้ไข Tag เดิม และมองเห็น Tag บนแถว Texture
- ช่องค้นหา Drawable ด้านซ้ายค้นจาก Tag ของ Texture โดยไม่แยกตัวพิมพ์เล็กใหญ่ เมื่อพบจะแสดง Drawable ที่มี Texture นั้น การค้นหาชื่อและ Tag ของ Drawable เดิมยังทำงานเช่นเดิม
- Tag เป็นข้อมูลของโปรเจกต์ บันทึกไปพร้อมกับ Texture เมื่อเปิดโปรเจกต์อีกครั้ง Tag ยังอยู่ โดยไม่เปลี่ยนชื่อไฟล์ Texture หรือผลลัพธ์ในเกม
- เมื่อแทนที่ Texture หรือคัดลอก Drawable ไปอีกเพศหนึ่ง Tag ของ Texture จะติดไปด้วย โปรเจกต์เดิมที่ยังไม่มี Tag ของ Texture จะเปิดได้ตามปกติ
- ผลการค้นหาปรับตามทันทีเมื่อเพิ่มหรือลบ Tag ของ Texture

## ขอบเขต

งานนี้ครอบคลุม Texture ปกติที่แสดงเป็นแถวในแท็บ Textures ยังไม่รวม Embedded Texture ประเภท Specular และ Normal ช่องค้นหาด้านซ้ายยังค้นเฉพาะ Addon ที่กำลังเปิดอยู่เช่นเดิม

## การเลือกผลการค้นหา

เมื่อค้นพบ Tag ของ Texture ให้โปรแกรมเลือกแถว Texture ที่ตรงให้อัตโนมัติ หากมีหลายผลลัพธ์ให้เริ่มที่ Drawable แรกในรายการ และเมื่อผู้ใช้เลือก Drawable ผลลัพธ์อื่น ให้เลือก Texture ที่ตรงภายใน Drawable นั้น
